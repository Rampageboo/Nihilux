First installable release of **Nihilux** (formerly Storyboarder).

- Windows installer for the current user: no administrator rights, no Python, Node or ffmpeg to install. Python 3.14, LGPL ffmpeg/ffprobe, the Photoshop plugin and the Blender add-on are bundled.
- Updates itself from GitHub Releases: checks at start and in **Settings → Updates**; **Install and restart** verifies the signed update before installing it.
- **Settings → Integrations**: install the Photoshop panel, open the Blender add-on folder, and copy an MCP config so Claude Code or Codex can drive the app.
- App state is kept in `%APPDATA%\StoryboardTool` and survives updates and uninstalling; projects stay where you saved them.

The installer is not code-signed yet: if Windows SmartScreen warns, choose **More info → Run anyway**.
