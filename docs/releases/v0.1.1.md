# Nihilux v0.1.1

- Fix the drawing editor creating a new layer for every stroke. Pen and eraser strokes now stay in the current drawing layer; use **New layer** to create another. Switching tools retains the selected layer, and undo/redo still works per stroke.
- Preserve editable drawing layers when saving and reopening. Existing standalone objects in older drawings remain intact.
- Rename the MCP server identity to `nihilux` and all 23 tools to `nihilux_*`. Old `storyboard_*` tool names are removed; refresh the MCP connection after updating.
- Update server instructions, generation handoff prompts, development registrations, Windows launcher, and agent documentation to use the new names.
- Development MCP registrations now resolve the checkout through `scripts/nihilux-mcp.cmd` instead of requiring a fixed D: drive path.
- Existing projects, data folders, the `storyboard_tool` Python package and the authentication header remain compatible.

The companion shared skill is now named `nihilux-filmmaking` and uses the new tool names. Refresh the skill and MCP connection together when updating.
